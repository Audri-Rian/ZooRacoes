# Rotina Diária do Dono

Checklist operacional amarrado ao painel.

## Abertura

- [ ] Abrir painel ZooRações
- [ ] Ver pedidos `novo` / `confirmado`
- [ ] Ver agenda do dia (`confirmado` e `solicitado`)
- [ ] Ver fila de **lembretes** (hoje / vencidos)
- [ ] Checar produtos críticos (ração top) — pausar se acabou

## Durante o dia

- [ ] Confirmar pedidos novos e avisar no WhatsApp
- [ ] Atualizar status (`preparando` → `pronto` → `retirado/entregue`)
- [ ] Confirmar ou remarcar agendamentos solicitados
- [ ] Enviar lembrete WhatsApp de agenda quando fizer sentido
- [ ] Avisar tutores com lembrete de cuidado (vacina etc.) e registrar retorno quando vierem
- [ ] Atender balcão normalmente; usar painel como fila

## Fechamento

- [ ] Não deixar pedido `novo` sem decisão (confirmar ou cancelar com motivo)
- [ ] Marcar no-shows / conclusões da agenda
- [ ] Revisar lembretes vencidos sem aviso (avisar, adiar ou dispensar)
- [ ] Revisar itens que zeraram
- [ ] (Opcional) Olhar pedidos do dia seguinte se já houver

## Mapa tela → ação

| Tela do painel | Ação do dono |
| --- | --- |
| Pedidos | Confirmar, preparar, avisar, concluir |
| Agenda | Confirmar, remarcar, concluir, no-show |
| Lembretes | Avisar WhatsApp, registrar cuidado, adiar, dispensar |
| Produtos | Pausar, preço, disponibilidade |
| Clientes/Pets | Cadastrar, ficha, histórico de cuidados |

## Objetivo da rotina

Transformar o dia em **fila clara**, não em histórico infinito de chat.
