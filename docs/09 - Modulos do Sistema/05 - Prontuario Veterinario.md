# Módulo — Prontuário Veterinário

Onde o sistema fica especializado em clínica. Tudo ancorado no **Animal**.

## Blocos do prontuário

### Histórico clínico / consultas
- Consultas
- Anamnese
- Diagnósticos
- Sintomas
- Evolução

### Sinais vitais e medidas ao longo do tempo
- Peso
- Temperatura
- Frequência cardíaca
- Frequência respiratória
- Observações

### Prescrição
- Medicamento
- Dosagem
- Frequência
- Duração
- Via de administração
- Observações

### Exames (visão clínica; lab detalha o fluxo)
- Solicitação
- Resultado
- PDF / imagens
- Data
- Veterinário responsável

### Documentos
- Receitas
- Atestados
- Laudos
- Termos
- Arquivos anexados

## Papéis

| Papel | Acesso típico |
| --- | --- |
| Veterinário | Escreve prontuário, prescreve, solicita exame |
| Operador/atendente | Agenda, cadastro; acesso clínico conforme permissão |
| Tutor | Não edita; pode receber documentos via WhatsApp |

## Compliance (atenção)

- Prontuário e receita envolvem responsabilidade profissional (CRMV) e LGPD
- Assinatura / identificação do veterinário responsável é requisito de produto nas fases clínicas
- Não é “bloco de notas”: auditoria de quem alterou o quê
